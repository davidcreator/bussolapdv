# Roadmap

> **Projeto:** Bússola Sistema PDV Open Source

Todas as etapas estão pendentes.

1. [ ] Aprovar requisitos, políticas fiscais e limites de implantação.
2. [ ] Estruturar código, migrações, CI e ambiente local.
3. [ ] Implementar usuários, permissões, parâmetros, produtos e clientes.
4. [ ] Implementar estoque, fornecedor e caixa.
5. [ ] Implementar PDV atômico, pagamentos e testes de falha.
6. [ ] Implementar crediário, recebimentos, cancelamento e devoluções.
7. [ ] Implementar auditoria, fechamento e dashboard.
8. [ ] Implementar backup, restore, importação opcional e empacotamento.
9. [ ] Executar QA, revisão jurídica/fiscal, segurança, privacidade e homologação.
10. [ ] Publicar release somente após aprovação dos responsáveis e evidências.
